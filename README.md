# Obsidian AI · учебная PWA (PAE-05 TEST)

Это **публичная тестовая демонстрация**. В приложении находятся только три вымышленные заметки. К настоящему Obsidian Vault, Mac, iCloud, OpenAI API или Gateway оно **не подключается**. Кнопка открытия демо **не является авторизацией**. Редактирование реальных документов и хранение личных данных отключены.

## Для iPhone

Откройте адрес GitHub Pages в Safari → «Поделиться» → «На экран „Домой“». Проверяйте поиск, просмотр заметок, чат и возврат из другого приложения. Сейчас приложение **online-only**, так как Service Worker/offline-кэш не включён. Публикация ZIP не доказывает работоспособность на iPhone: требуется отдельный реальный тест устройства.

## GitHub Pages

Содержимое архива рассчитано на **корень отдельного публичного репозитория** `pae05-obsidian-pwa-test`. Для GitHub Free: Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save. Это действие потребуется выполнить владельцу, если его нельзя выполнить через подключённый GitHub. При публикации сайт будет общедоступен.

## Безопасность

Использовать только как синтетический тест. Не добавлять сюда пароли, ключи, реальные заметки, медицинские файлы, снимки личных экранов и секреты. Публичный сайт раскрывает клиентский HTML/CSS/JS посетителям. Этот комплект не является полноценным Gateway и не означает согласие на production release.

Проверенный исходный кандидат: PAE-05 CP-P13/CP-P14, Chrome Headless QA 19/19 PASS_SCOPED; Safari/iPhone **NOT RUN**.
